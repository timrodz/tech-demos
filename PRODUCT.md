# Demo Lab Product Context

## Purpose

Demo Lab is Juan's personal collection of hyper-specific frontend technology demonstrations. Each demo focuses on teaching one sharp, well-defined technique or emerging frontend capability — such as vGPU usage, Vercel Labs experiments, or novel AI-driven frontend interactions.

## Users

- **Primary**: Juan (repository owner), exploring and documenting cutting-edge frontend techniques
- **Secondary**: Visitors, developers, and potential collaborators viewing Juan's portfolio work

## Design Philosophy

The demos themselves are the stars. Each one can be as vivid, experimental, or technique-specific as needed. However:

- **UI chrome must feel like Juan's portfolio** — not generic AI-generated interfaces
- Control panels, navigation, and supporting UI should match the portfolio's clean, calm aesthetic
- Demos showcase technical depth; the surrounding interface proves craft and attention to detail

## Accessibility Expectations

- Readable controls with sufficient contrast
- Keyboard-usable interfaces where practical
- Clear labeling for interactive elements
- Control panels should be accessible and intuitive

## Anti-Patterns to Avoid

This is a personal portfolio of technical demos, not a generic SaaS product. Avoid:

- Generic AI-generated aesthetic ("AI beige")
- Status-chip soup and unnecessary UI decoration
- Pulsing dots and skeleton loaders unless the demo technique requires them
- Italic serif decoration that dilutes the clean, modern feel
- Over-engineered chrome that distracts from the demo content
